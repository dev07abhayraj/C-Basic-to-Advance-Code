<h2>⚙️ How to Run C Programs</h2>

<pre>
1. Open terminal / command prompt
2. Compile program:

   gcc filename.c -o output

3. Run program:

   ./output        (Mac/Linux)
   output.exe      (Windows)
</pre>

<hr>

<h2>🛠️ C Installation Guide</h2>

<h3>💻 For Windows</h3>

<pre>
1. Download MinGW from:
   https://www.mingw-w64.org/

2. Install and add to PATH:
   C:\MinGW\bin

3. Verify installation:
   gcc --version
</pre>

---

<h3>🍎 For macOS</h3>

<pre>
1. Install Xcode Command Line Tools:

   xcode-select --install

2. Verify:
   gcc --version
</pre>

---

<h3>🐧 For Linux (Ubuntu)</h3>

<pre>
1. Install GCC:

   sudo apt update
   sudo apt install build-essential

2. Verify:
   gcc --version
</pre>
